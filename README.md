# Avetaar GLM-AI

أداة GLM AI في ملف واحد — بدون مفاتيح API، بدون حساب. انسخها وشغلها.

## ✨ المميزات
- ⚡ **محادثة نصية** — بث مباشر عبر كامل عائلة نماذج GLM، من الأسرع إلى الأقوى
- 🖼️ **توليد الصور** — من وصفك، مع خيار صورة مرجعية للتعديل
- 👁️ **سؤال عن صورة** — أرفق أي صورة واسأل عنها
- 🪶 **خفيفة** — ملف واحد وتبعية واحدة فقط
- 🛡️ **أخطاء واضحة** — انتهاء الجلسة، حدود الاستخدام، الرصيد المتبقي

## التثبيت والتشغيل

Windows:
```
git clone https://github.com/Avetaar/AvetaarGLM-AI.git && cd AvetaarGLM-AI && python -m venv venv && venv\Scripts\activate && pip install -r RIVAL_requirements.txt && python AvetaarGLM-Ai.py
```

Linux / macOS:
```
git clone https://github.com/Avetaar/AvetaarGLM-AI.git && cd AvetaarGLM-AI && python3 -m venv venv && source venv/bin/activate && pip install -r RIVAL_requirements.txt && python AvetaarGLM-Ai.py
```

# Avetaar GLM-AI

A single-file GLM AI client — no API keys, no accounts. Clone it and run it.

## ✨ Features
- ⚡ **Text chat** — live streaming across the full GLM lineup, fastest to strongest
- 🖼️ **Image generation** — from your prompt, with an optional reference image for editing
- 👁️ **Image questions** — attach any image and ask about it
- 🪶 **Lightweight** — one file, one dependency
- 🛡️ **Clear error states** — expired sessions, usage limits, remaining balance

## Install & Run

Windows:
```
git clone https://github.com/Avetaar/AvetaarGLM-AI.git && cd AvetaarGLM-AI && python -m venv venv && venv\Scripts\activate && pip install -r RIVAL_requirements.txt && python AvetaarGLM-Ai.py
```

Linux / macOS:
```
git clone https://github.com/Avetaar/AvetaarGLM-AI.git && cd AvetaarGLM-AI && python3 -m venv venv && source venv/bin/activate && pip install -r RIVAL_requirements.txt && python AvetaarGLM-Ai.py
```
